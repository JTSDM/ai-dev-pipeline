# TICKETS.md —— 任务清单模板

> 由 Tickets 阶段产出，落在 `.ai-workflow/TICKETS.md`。过程文件，任务完成后归档或删除，只留验收记录。
> **竖切不横切**：一个 ticket 穿透所有层（数据+逻辑+界面+测试），完成后是端到端可验证的切片。

## 正式任务区

| # | 任务 | 验收标准（映射测试） | 标签 | 状态 |
|---|------|---------------------|------|------|
| 1 | 例：实现历史净值导出 API | 见 SPEC §5 验收 1-3 | AFK | ✅ |
| 2 | 例：前端导出按钮 + 下载交互 | 点击后下载文件且格式正确 | HITL（按钮文案需确认） | ⏳ |

- 标签：`HITL`（需人决策）/ `AFK`（可完全交给 AI）
- 状态：`⏳ 待做` / `🔄 进行中` / `✅ 完成` / `❌ 取消`

## 临时任务区（S 档）

> S 档最小任务描述追加到这里，一行一条，完成后打勾。

```markdown
- [ ] 修复历史净值导出日期格式错误
  验收标准：导出 CSV 中 date 列为 YYYY-MM-DD，且与页面展示一致
  测试：新增/修改单测覆盖该格式转换
- [ ] 结果：已完成，测试通过（YYYY-MM-DD）
```
